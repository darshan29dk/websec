# AEGIS Phase 4 — Investigation Workspace

## Workflow Lifecycle
1. Incident Creation (from Correlated Detections)
2. Investigation Creation & Assignment
3. Telemetry Event & Finding Review
4. Timeline Ordering (Strictly by actual event time)
5. Hypothesis Creation & Evidence Attachment (Supporting / Contradicting / Neutral)
6. Analyst Notes & Summary
7. Investigation Conclusion Determination

## Valid Conclusions
- `CONFIRMED`
- `LIKELY`
- `SUSPICIOUS`
- `INCONCLUSIVE` (Preferred when telemetry evidence is incomplete)
- `FALSE_POSITIVE`
